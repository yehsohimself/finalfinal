# Shared look

`stil.css` is the common visual language for every product built here: copy it into `site/`, link it from `site/index.html`,
and set `--accent` to suit the product. Keep the page quiet and the idea loud: one accent colour, one primary button, a plain headline.

Delete this `_sablon/` folder before the work is committed; it is scaffolding, not part of the product.
