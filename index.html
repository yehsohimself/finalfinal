    How it works

    Four layers, six knobs.
    The poster is an SVG with a title, a logo, a product and a background. A comment can only change size, colour, rotation, position, type weight or shadow.
    A local model reads the comment.
    Run it locally and the comment goes to a small model in Ollama, which returns a change list: [{element, property, value}]. Nothing leaves your machine.
    A rulebook when there is no model.
    This page works on its own with fourteen rules for the classics: bigger means +30%, pop means saturation plus a tilt, whiter means an optical brightener.
    Every version is archived and scored.
    Drift from v1 is measured pixel by pixel. With the local server on, a vision model also judges each version: was the comment met, and how far did we drift.

    Try it locally, with the model

    1. Install Ollama and pull a small vision model: ollama pull gemma3:4b
    2. Get the code: git clone https://github.com/OWNER/finalfinal && cd finalfinal
    3. Start it: uv run server.py (or pip install flask && python3 server.py)
    4. Open http://127.0.0.1:5027 and type what your client said.
